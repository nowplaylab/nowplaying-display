# NowPlaying — памятка для ИИ-агентов и разработчиков

Этот файл — чтобы любой агент (Claude, Gemini, ChatGPT/Codex и т. п.) или человек мог продолжить работу без истории переписки. `CLAUDE.md` и `GEMINI.md` ссылаются сюда.

## Что это

Экран «Сейчас играет» для старых Android-устройств. Сервер на ПК с Windows берёт трек из системной панели мультимедиа (и из VLC), находит обложку, текст песни, видео, и по домашней сети отдаёт всё приложению на планшете или телевизоре. Когда музыка не играет — часы, погода, виджеты, будильник.

- Главное устройство: Samsung Galaxy Tab 3 Lite SM-T110, Android 4.2, экран 1024×600. Второе — Mi TV (Android TV 11, 1920×1080).
- Репозиторий: https://github.com/nowplaylab/nowplaying-display (организация nowplaylab, MIT). Сайт: https://nowplaylab.github.io/nowplaying-display/ (папка `site/`, публикуется `.github/workflows/pages.yml`).
- Язык проекта — русский: комментарии, интерфейс, коммиты. README двуязычный: `README.md` (английский) и `README.ru.md` — любую правку делать в обоих.

## Устройство

```

  settings.py             настройки %LOCALAPPDATA%\NowPlaying\settings.json; DEFAULTS, UI_KEYS (уходят планшету),

  settings_web.py         окно настроек /settings и /api/settings/* (только с 127.0.0.1 + заголовок X-NowPlaying)
  settings_ui/index.html  само окно настроек (один файл, без сборки)
  yandex.py               открытое API Яндекс Музыки: видеошоты и превью клипов, запасной текст

  weather.py, widgets.py, calendar_ics.py, pcstate.py, photoframe.py   экран часов
  updater.py              автообновление exe и APK с GitHub Releases

design/                   макеты, иконки, генераторы картинок
```

## Запуск и проверка

- Сервер из исходников: `cd pc && python -m venv .venv && .venv/Scripts/python -m pip install -r requirements.txt pyinstaller`, затем `.venv/Scripts/python server.py`. Рабочий порт 47801 (HTTP) и 47800 (UDP-поиск).
- **Тестировать на другом порту**, чтобы не мешать рабочему серверу пользователя: `NP_HTTP_PORT=47811 NP_UDP_PORT=47812 LOCALAPPDATA=<временная папка> python server.py`. С 2.5 и собранный exe на другом порту можно запускать рядом с рабочим (свой мьютекс).
- **Никогда не жать кнопки управления (пауза, следующий, громкость) на устройстве, подключённом к рабочему серверу** — это управляет настоящей музыкой пользователя. Для проверок — подставные серверы, устройство переключать на тестовый адрес и потом возвращать.
- Подсветка без ламп: `tools/lamp-test/` (подставной Яндекс + 21 проверка).
- Окно настроек: http://127.0.0.1:47801/settings (с другого компьютера не открывается — так задумано).

## Сборка

- APK: `ANDROID_SDK=<путь к SDK> sh android/build.sh` (нужны build-tools 34.0.0, platforms android-17 и android-21, ключ подписи `nowplaying.keystore` в папке SDK — его в репозитории нет). Сборка идёт во временной ASCII-папке: инструменты Android ломаются на кириллице в пути. assets добавляются через `jar uf0`, потому что aapt2 на Windows пишет их с обратной косой.
- exe: `BUILD_DIR=<временная папка> sh pc/build_exe.sh` → `release/NowPlayingServer.exe`. Копирует все `pc/*.py` разом (в 2.4 модуль забыли — программа падала).
- **После сборки exe обязательно запустить его на тестовом порту** и проверить `/health` и `/api/settings` (заголовок `X-NowPlaying: 1`).
- Секрет приложения Яндекса для подсветки: файл `pc/yandex_secret.py` (`SECRET = '...'`), в `.gitignore`. Без него exe собирается, но вход в Яндекс не работает. Значение видно владельцу приложения на oauth.yandex.ru.

## Версии и выпуск

- Версия программы — `VERSION` в `pc/server.py` (= тег релиза `vX.Y`). Версия приложения — `versionName`/`versionCode` в `android/AndroidManifest.xml`. Если планшетная часть не менялась, APK не пересобирать и выкладывать со старым именем.
- **Имя APK в релизе обязано совпадать с versionName внутри него** (`NowPlaying-2.4.apk`), иначе планшет переустанавливает его по кругу.
- Каждый опубликованный релиз сам доезжает до ПК и планшета (автообновление) — публиковать только проверенное и только с согласия владельца.
- Выпуск по одной версии в день: готовую версию выкладывать **черновиком** (`tools/make-draft.sh`), `daily-release.yml` в 12:00 МСК публикует самый младший черновик новее latest. Версии строятся одна поверх другой, сравнение числовое (2.9 < 2.10).
- `tools/update-now.bat` — владелец ставит самую свежую версию сразу, включая черновики.

## Подводные камни (проверено на практике)

- PyInstaller onefile: запуская свой exe через Popen, ставить `PYINSTALLER_RESET_ENVIRONMENT=1`, иначе новая копия берёт временную папку старой и падает.
- `comtypes` нельзя импортировать в основном потоке — ломает winrt.
- Android 4.2: ViewPropertyAnimator/ObjectAnimator при частых перезапусках сразу ставят конечное значение. Анимация высоты строк текста («Сцена», «Минимал») сделана через ValueAnimator по высоте; вариант со сдвигом владелец отверг.
- У планшета системное UTC отстаёт, а tzdata старая: всё, что считается от настоящего UTC, поправлять на разницу с часами ПК (`server_time_ms` → `skewMs`).
- Телевизор: скриншот экрана при видео выходит белым — читать экран через `uiautomator dump`. Окно адреса сервера открывается кнопкой MENU.
- На ТВ стоит VPN, широковещательный поиск не проходит — приложение ищет ПК перебором /24 по `/health`.
- Яндекс Музыка: полный клип без аккаунта недоступен (no_licenses), берутся видеошоты и 10-секундные превью; у превью максимум 720p. Синхронный текст Яндекса требует аккаунт.
- Musixmatch, NetEase и подобные защищаются от ботов — не обходить. YouTube с ПК напрямую не работает. Всё должно работать с самого ПК, без своих серверов-посредников.
- Лампы Яндекса управляются только через облако (0,5–1 с задержки) — «под бит» через них не делать.
